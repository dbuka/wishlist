# Вишлист Агаты

## Опубликовать на GitHub Pages

1. Запусти `node server.js` и открой <http://127.0.0.1:3000/>. Для экспорта уже добавленных подарков открой редактор в том же браузере и по тому же адресу, где их добавляла. Нажми «Экспортировать для публикации» и замени скачанным файлом `docs/gifts.json`.
2. В Supabase создай проект и запусти содержимое `supabase/reservations.sql` через **SQL Editor**. Скопируй URL проекта и его публичный ключ **Publishable key** (`sb_publishable_…`) в `docs/booking-config.json`. Файл будет публичным. Секретные ключи Supabase туда добавлять нельзя.
3. Открой <http://127.0.0.1:3000/wishlist/>. Проверь, что видны карточки и можно забронировать подарок. Открой тот же адрес в другом браузере и проверь статус. Удали пробную бронь через **Table Editor → gift_reservations**.
4. Создай пустой репозиторий `wishlist` на GitHub. Из этой папки выполни команды, подставив адрес своего репозитория.

   ```sh
   git init -b main
   git add .
   git commit -m "Prepare wishlist for GitHub Pages"
   git remote add origin https://github.com/USERNAME/wishlist.git
   git push -u origin main
   ```

5. В репозитории открой **Settings → Pages** и выбери **Deploy from a branch → main → /docs → Save**. После публикации ссылка для друзей будет вида `https://USERNAME.github.io/wishlist/`.

Сайт открытый. Любой, кто откроет страницу, сможет увидеть подарки и забронировать их. База хранит только ID подарка. Чтобы снять бронь, удали строку с соответствующим ID в **Table Editor → gift_reservations**.

## Обновить список

После правок в редакторе снова экспортируй список, замени `docs/gifts.json` и отправь изменения на GitHub. Редактирование карточки сохраняет её ID и бронь. Если удалить карточку и добавить её заново, у неё будет новый ID.

Если меняешь разметку, стили или скрипты, запусти `node build-pages.js` и добавь обновлённые файлы из `docs` в коммит. Сборка сохраняет `gifts.json` и настройки Supabase.
